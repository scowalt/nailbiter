# Synthetic pro-hype scenarios

Every JSON file here is independently generated by `scripts/test-fixtures/generate.py`; none is a provider capture. Team IDs, route URLs and some legacy filenames are compatibility identifiers, not historical claims. Source timestamps and probabilities are constructed controls.

Coverage includes season progress, postseason/play-in labels, first-inning pregame eligibility, same-team schedules, qualification-only Stakes with ignored seeding metadata, quote normalization and actual importer-to-page wiring. See the [central fixture contract](../../../../tests/fixtures/README.md) for regeneration, provenance and limits. Historical observations and their original checksums remain private archival evidence, not dependencies of these tests.
