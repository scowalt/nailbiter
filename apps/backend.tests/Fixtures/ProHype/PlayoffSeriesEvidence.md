# Synthetic playoff-series contracts

The generated MLB case is an invented best-of-three series tied 1–1 before game three. Prior completed results, both schedule copies, the future event and series metadata are constructed together. Other generated cases cover the NBA/NHL/MLB round-label grammar.

The tests exercise real collection/persistence/page behavior, atomic observations, stale or conflicting evidence and unsupported phases. These are implementation contract tests, not captured playoff results. See [fixture provenance](../../../../tests/fixtures/README.md).
