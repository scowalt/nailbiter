# Constructed chart histories

`histories.csv` and `context.json` are deterministic synthetic staircase cases generated by `scripts/test-fixtures/generate.py`. They replace historical captures for public regression coverage; they do not replace or redefine the private historical evidence.

`SyntheticExcitementHistory.Load` verifies the fixture hash, exact columns, count, ordering and cutoff. `HostedGameFixture.SeedSyntheticHistoryAsync` exercises the actual in-process application and isolated PostgreSQL while blocking external provider HTTP. HTTP checks compare all chart fields against the independently generated file and preserve the latest-100 API limit, microsecond precision, bounds and explicit eligibility controls.

The independently integrated totals are 20.83333 and 56.16, with literal test anchors and a rational-number Python oracle. See [fixture specification](../../../../tests/fixtures/README.md). Passing these constructed scenarios is not new empirical calibration or live observation evidence.
