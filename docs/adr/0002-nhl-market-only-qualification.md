# Use gambling-market evidence only for NHL playoff qualification

**Partially superseded on 2026-10-11:** [ADR 0003](0003-nhl-moneypuck-qualification-exception.md) allows the specifically user-approved MoneyPuck forecast source. The decisions below remain the October 10 record; other model forecasts, PlayoffStatus and Polymarket are still rejected. No MoneyPuck runtime implementation is enabled.

On 2026-10-10 the user rejected model-derived NHL playoff qualification forecasts, including forecasts scraped from other websites, in favor of probabilities derived from actual gambling-market prices. New sources must be free-only; target all 32 teams under normal operation, but retain unavailable states when all approved evidence is missing or expired rather than fabricate coverage.

This deliberately forgoes model forecasts' independence from trading liquidity. The previously default-off PlayoffStatus model fallback is rejected, not awaiting permission to enable; MoneyPuck's independent team-strength rankings are outside this decision. Polymarket remains separately rejected. A sportsbook or market-price aggregator still needs verified qualification-market identity, existing free recurring access/reuse permission, freshness and full-league coverage before integration. The user declined written permission requests; do not pursue sources requiring additional consent or reinterpret public readability as authorization. Free self-service API-key registration without payment or permission correspondence is allowed for evaluation, but does not by itself approve a provider or its coverage.

The user approved proportionally removing the bookmaker margin from a same-book make/miss pair (`p_make / (p_make + p_miss)`) and retaining eligible Kalshi evidence ahead of a sportsbook-price fallback. Do not mix books' opposing prices or average Kalshi and sportsbook probabilities. No specific fallback provider or runtime implementation is approved by these decisions alone.
